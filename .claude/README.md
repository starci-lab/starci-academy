# `.claude/` — canon cho AI

Thư mục này là **nguồn-sự-thật mà Claude đọc** để build/mở rộng repo an toàn. Nội dung ở
đây là canon, không phải bản sao.

## Cấu trúc

| Thư mục | Là gì |
|---|---|
| `design/` | Canon design-system Storybook — `test-strategy.md` (test = hợp đồng DOM) + `storybook/architecture/{split, elements/tiers, principles/{gap,padding,responsive}}`. |
| `rules/` | Luật repo. |
| `skills/` | *(thầy tạo sau)* — hệ thống skills của Claude. |
| `docs-site/` | **Docusaurus** — trang docs render `.claude/` để đọc/duyệt. |
| `worktrees/` | Git worktree tạm (bỏ qua). |

## Docs = Docusaurus (render `.claude/` TẠI CHỖ)

Trang docs dùng **Docusaurus**, đặt ở `.claude/docs-site/`. Điểm mấu chốt: nó **trỏ
`docs.path: '..'` thẳng vào `.claude/`** (native external-dir của Docusaurus) — **KHÔNG
copy, KHÔNG sync script**. Nguồn-sự-thật vẫn nằm nguyên ở `.claude/{design,rules,skills}/`;
Docusaurus chỉ đọc và render.

- Vì sao Docusaurus (không Nextra): Nextra v2 **không có** config external-content-dir
  native → phải viết script sync. Docusaurus làm out-of-the-box qua `docs.path`. (thầy chốt 2026-08-03)
- **Skills tự lên docs**: khi `.claude/skills/**/*.md` xuất hiện, sidebar autogenerated
  của Docusaurus tự thêm — không cần đụng docs-site.

### Chạy
```bash
cd .claude/docs-site
npm install
npm start   # → localhost:3030
```

> Sửa docs = sửa file `.md` trong `.claude/**` (nơi Claude cũng đọc). Docusaurus chỉ là
> lớp hiển thị; đừng viết nội dung canon bên trong `docs-site/`.
